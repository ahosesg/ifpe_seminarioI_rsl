# Fontes brutas e arquivos enviados

Este diretório contém exportações bibliográficas, textos completos, documentos
PRISMA, planilhas recebidas e demais fontes originais do projeto.

Regras:

- não renomear ou mover arquivos já citados nas bases de rastreabilidade;
- não editar exportações RIS, NBIB ou documentos originais;
- manter nomes repetitivos fornecidos pelas plataformas, pois eles identificam
  a origem real de cada lote;
- registrar interpretações, deduplicação e decisões somente em `dados/`;
- novos arquivos enviados pelo Prism devem permanecer neste diretório.
